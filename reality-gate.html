Execution Architecture & Evidence Flow

Every node in this architecture corresponds to an implemented capability in the local product runtime.

When a workflow executes through Reality Gate, the platform creates a temporary local clone, executes whitelisted commands inside that sandbox, collects execution logs and artifact checksums, and signs the outcome before persisting the receipt to the local Proof Ledger.

  • Zero Authority Mutation: User source repositories and remotes are never edited or rewritten.
  • Local Cryptographic Keys: ECDSA P-256 keys are generated and held locally in AppData.
  • Offline Execution Safety: Drills remove remote network credentials to verify true local operation.

Explicit Developer Pilot Limits & Plain-Language Boundaries

  • Windows Only: Supported on Windows 10/11 x64. No macOS or Linux packages are available.
  • Unsigned Package: Windows SmartScreen may show "Windows protected your PC" on first launch — choose More info → Run anyway after verifying SHA-256.
  • Manual Update Model: No auto-updater; updates require fresh ZIP downloads and SHA-256 verification.
  • Local-First Scope: Local data is stored in AppData. No cloud accounts, cloud sync, or remote dashboards exist.
  • Plain-Language Boundaries: Receipts prove what was executed, hashed, and signed. They are not legal attestations, security certifications, or guarantees against third-party provider outages.

Install, update, uninstall & leftover data
Install
Download the ZIP, extract it, and run the installer inside. Windows SmartScreen may prompt on first launch — choose More info → Run anyway after verifying the SHA-256.
First run
The Developer Pilot opens to its control-room Home view (repository continuity status). A screen recording of the real interface is available in the product film above; no first-run account, sign-in, or cloud setup is required.
Update
Manual update model: no auto-updater. Updates require a fresh ZIP download and SHA-256 verification (see Download & Verify above).
Uninstall
The public source does not document a dedicated uninstaller. Because the pilot is a portable ZIP package, remove the extracted folder to remove the app. If you installed via an installer stub, use Windows Settings → Apps.
Leftover data
Local data (project registries, run logs, receipts, local keypairs) persists in %APPDATA%\RealityGate\ until you clear it; removing the app folder does not delete that directory. Delete %APPDATA%\RealityGate\ to remove all local data.

Privacy & Data Flow

Local execution. Verification on your terms.

Evidence-backed behavior for Reality Gate Windows v1.1.0 Developer Pilot.

01

Stored on your device

Project registries, build/test logs, ECDSA P-256 run receipts, and local keypairs are stored in your local %APPDATA%\RealityGate\ directory.

02

Network & transport boundaries

Core runroom execution runs locally without background cloud sync. Optional read-only MCP adapter listens on 127.0.0.1:8765 (loopback only). Remote Git sync uses system Git CLI when initiated by the user.

03

Telemetry & retention

Zero background telemetry, analytics tracking, or ad SDKs found in audited source. Receipts and registries persist locally until cleared by the user.
