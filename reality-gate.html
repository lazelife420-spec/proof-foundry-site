Reality Gate
Developer Continuity Platform

Developer Pilot

Keep your forge. Keep control of your work.

Reality Gate works alongside GitHub, GitLab, Forgejo, and ordinary Git. It helps you understand what your development depends on, verify whether your local operation can continue, and keep proof of what was checked. No migration required.

Keep GitHub. Keep GitLab. Keep Forgejo.

Reality Gate is the continuity layer underneath your existing workflow.

  • Existing Git repositories remain normal Git repositories.
  • Existing remotes remain usable.
  • Reality Gate analyzes local project/provider dependencies.
  • Reality Gate helps evaluate continuity.
  • Reality Gate produces proof/receipts.
  • No mandatory source migration.

Provider Compatibility

Reality Gate reads the Git workflow you already have rather than asking you to replace it.

  • GitHub
  • GitLab
  • Forgejo
  • Ordinary Git / local repositories

How It Works

  1. 1. Add a Git repository: Use an existing project or the included disposable demo repository.
  2. 2. See dependencies: Reality Gate identifies relevant local Git/provider configuration.
  3. 3. Check continuity: See what the current evidence says about your ability to keep working.
  4. 4. View proof: Review the evidence/receipt behind the result.

Your repository stays yours

The passive pilot workflow has been tested to leave the source repository unchanged while adding a repo, analyzing dependencies, checking continuity, and viewing proof.

No repository migration is required.

Requirements

  • Windows 10 / 11
  • Existing Git installation/project recommended
  • No mandatory Proof Foundry account for the individual continuity workflow

Because this is an early pilot build, Windows SmartScreen may show "Windows protected your PC". Click More info -> Run anyway.

What the evidence means

  • Configured provider dependency does not prove live provider availability.
  • Local source does not equal off-machine backup.
  • A continuity result is scoped to evidence Reality Gate actually checked.
  • This pilot does not claim every disaster scenario is recoverable.

Pilot Status

This build has passed internal packaged workflow and repository-immutability checks. The purpose of the pilot is to test Reality Gate against different developers, machines, repositories, and Git configurations.
