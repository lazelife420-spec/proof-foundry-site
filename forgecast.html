Known limitations

Honest about what this release does not do.

Requirements

  • Android 8+ (API 26+)
  • Sideload / Install Unknown Apps permission enabled
  • APK signed with the private ForgeCast signing identity (Android displays a sideload prompt)

Not included

  • No Community Checks backend server
  • No Day Receipts cloud sync
  • No automatic background auto-update

Honest widget scope

  • Widgets update with your weather — they are not continuously animated
  • Stale data shows an honest "may be outdated" state instead of pretending to be live
