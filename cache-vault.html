What it does

Clipboard history that stays on your machine, with receipts for everything.

Clipboard history & safes

Capture every clip automatically, then organize the ones that matter into named safes and collections.

Global search & Quick Paste

Find any clip fast across history and safes, and paste it back in one step with Quick Paste.

Command Center

Trigger actions from a single hotkey-driven launcher. Phase 1 ships Hotkey Actions; expansions wait for deliberate scope decisions.

Screenshots & images

Images live alongside text clips, so visual context is never lost between pastes.

Exports & proof packs

Bundle clips into exports and proof-pack workflows with stamped receipts you can inspect later.

Local-first storage

No cloud account, no telemetry. Your clipboard vault lives on your machine in durable files you own.

Android companion

An opt-in Mobile Bridge pairs Cache Vault Desktop with the production-signed CacheVault Mobile v0.2.1 companion over your own local network. There is no cloud relay and no account.

Current limitations & release state

What is true right now, including what is not yet released.

Current public release

{{product.versionLabel}} is the public desktop release, paired with the CacheVault Mobile v0.2.1 Android companion. The Windows build is not code-signed, so SmartScreen may prompt on first launch — verify the checksum above first.

v0.2.2 is prepared, not published

Cache Vault v0.2.2 is tagged in source, and its Windows artifact has been built and hash-verified. No public v0.2.2 artifact has been published and public distribution has not been authorized, so there is nothing to download under that version yet.

Command Center scope is frozen

Command Center is Phase 1 only (Hotkey Actions) in the current release. Later phases such as Text Expansions and Run Log UI are not claimed until they ship.
