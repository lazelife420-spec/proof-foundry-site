What is The Proof Foundry?

The Proof Foundry is an independent software studio making focused utilities for Windows and Android. Every public release ships with a record: what the release is, how to check the download, and what it does not do.

Principles

How we build

Four rules every product and every release follows.

Independent Products, Shared Standard

Each product installs and runs on its own. They share a release standard (published hashes, scoped claims, stated limits), not a platform, an account, or a runtime.

Local-First Principles

Local-first where product function permits. No account and no background tracking by default. Network-dependent functions such as ForgeCast weather transparently send the data required for those requests to the relevant service, as disclosed by the product.

Reality Gate's Role

Reality Gate is the studio's developer tool for building and checking releases. It runs builds in isolated local workspaces (the Runroom protects your working tree; it is not an OS security sandbox) and signs a receipt for each run. {{products.reality-gate.statusStatement}} It is not a required dependency for using consumer software such as Cache Vault, Cleanroom or GhostLayer.

Records You Can Check

Each public release has a Truth File listing its version, SHA-256 hash and known limits. Where a claim has no published evidence, the record says so instead of implying it.
