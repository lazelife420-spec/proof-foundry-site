About The Proof Foundry

Small tools. Kept honest.

The Proof Foundry is an independent studio making focused software for Windows and Android. Each tool does one job, runs on your machine where it can, and ships with a release record you can check.

Why "proof"?

Software descriptions are easy to write and hard to check. So every public release here comes with its exact file name, a published SHA-256 checksum, the tests it passed, and its known limits. If a claim isn't in the record, we don't make it.

How we work

Four rules we build by

They apply to every product, from a clipboard manager to a weather app.

Independent products, one standard

Every product stands on its own. There is no shared account, no required runtime, and no ecosystem to buy into. What they share is the release standard behind them.

Local first, where it fits

Local-first where product function permits: your data stays on your device unless a feature can't work without the network. No account is required, and there is no background tracking by default.

Network use is disclosed

Network-dependent functions such as ForgeCast weather transparently send the data required for each request, and the product page says what is sent and where. Nothing is collected silently, and there is no telemetry.

Where Reality Gate fits

Reality Gate is our developer tool for running builds in an isolated copy of a project and signing a record of the result. We use it to qualify our own releases. You never need it to use Cache Vault, Cleanroom, GhostLayer, or anything else we make.
