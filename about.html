What is The Proof Foundry?

The Proof Foundry is an independent software studio dedicated to creating focused, high-utility tools for desktop and mobile environments. We design software around personal utility, local control, and evidence-backed engineering discipline.

How We Work

The principles connecting our tools and release practices.

Independent Products, Shared Standard

Each product at The Proof Foundry functions independently. Our tools share a verification philosophy and quality standard—not a mandatory platform runtime or locked ecosystem.

Local-First Principles

Local-first where product function permits. No mandatory account/background tracking by default. Network-dependent functions such as ForgeCast weather transparently send the data required for those requests to the relevant service, as disclosed by the product.

Reality Gate's Role

Reality Gate is our engineering, control, and proof plane. It provides local runroom execution, ECDSA receipt signing, and Git project integration. It is an independent power tool for developers, not a required dependency for using consumer software like Cache Vault, Cleanroom, or GhostLayer.

Network Transparency

When a product requires external data—such as ForgeCast weather queries—it communicates over explicit, disclosed network endpoints without silent background tracking or telemetry collection.
