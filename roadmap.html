Research & architectural lineage+

Platform directions

Distinct development and delivery directions explored across The Proof Foundry environment:

  • Reality Gate Agent Gateway: Planned future bridge for local coding agents to inspect projects and request governed runs. Implementation and release status remain separate from the current pilot download.
  • Android Proof Foundry Store: Substantial pre-production/internal distribution line; not claimed as public production.
  • Windows Store / Launcher: Prototype / earlier implementation direction for integrated desktop catalog launching.
  • Proof Foundry Developers: Publisher and release-authoring direction, distinct from the consumer software catalog.
  • Website Storefront: future public Store/catalog direction building on today's direct-download pages and verified receipt model.
  • Reality Gate: Separate engineering proof and control plane powering automated qualification.

Architectural lineages

Historical research lineages that inform operator workspaces and execution controls:

  • NeuralShell & ProofForge: Historical architectural lineages explored for operator command interfaces and build controls. Preserved as lineage context, not shipped Reality Gate capabilities.
  • RECEIPT Desktop: Historical Windows Cleanroom receipt viewer and verifier companion line.

Earlier product lineages

Explored and preserved product concepts from earlier engineering tranches:

  • ProofBound: NeuralBook / MindUnset proof-backed interactive book, reader, and format lineage. Preserved concept; no public release claimed.
  • Sound Assist / Quiet Now: Separate Android accessibility product lineage explored in earlier research. Preserved concept; no public release claimed.
