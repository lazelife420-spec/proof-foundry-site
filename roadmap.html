NEXT PLATFORM LAYER

Reality Gate Agent Gateway

The next major platform direction is a standard agent bridge so local coding agents can query and use Reality Gate without bypassing its proof and authority model.

The design draws selectively from earlier Proof Foundry / NeuralShell architecture: operator sessions, bounded execution, capability requests, and intent gating—while Reality Gate remains the authoritative control and receipt layer.

Design now. Implement after self-hosting proof.

MCP v1 is intentionally narrow: project status, pipeline inspection, governed runs, logs, source state, and receipt verification. Arbitrary shell, unrestricted Git, release, and deployment operations are outside the first bridge.
