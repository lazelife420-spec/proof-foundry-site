# Binding design versus implemented website

The supplied designs are binding composition/material authority. Reference01 is the primary design; references02–04 establish the same cinematic family. The rejected prior candidate is preserved for context. This document evaluates the actual built page, not a proposed mockup. `BINDING_DESIGN_VS_IMPLEMENTATION.png` places the complete primary reference on the left and the complete final1440px native browser capture on the right at equal1024px displayed widths. Both retain their original proportions; the implementation is not stretched or cropped to conceal differences.

## Masthead

REFERENCE DESIGN = Thin dark editorial masthead, PF wordmark, sparse links and gold-outline software action.

ACTUAL IMPLEMENTATION = Homepage-only72px masthead, real selected G, stacked serif wordmark, four navigation links, studio doctrine and gold-outline action; mobile uses the working keyboard-accessible menu.

WHAT NOW MATCHES = Spacing, restrained border, display identity, sparse navigation and action hierarchy.

WHAT STILL DOES NOT = The concept's antique serif PF symbol differs from the selected geometric G.

WHY ANY DIFFERENCE IS NECESSARY = G is the current owner-selected identity. The shared product/catalog header remains frozen.

## Hero

REFERENCE DESIGN = Oversized serif headline against a physical foundry; foreground workbench, monumental maker object, distant warm light and cool steel; CTAs and principles occupy the calm left field.

ACTUAL IMPLEMENTATION = A photographic decorative workshop and blank blackened-steel ledger carry the unchanged G SVG and real HTML maker typography. The original headline and warm second line sit left; genuine Cache Vault Quick Paste overlaps the foreground bench. Independent, inspectable and bounded local-first principles remain below the actions.

WHAT NOW MATCHES = Physical richness, object scale, three depth planes, light direction, warm/cool contrast, left negative space, large serif hierarchy and overlapping foreground evidence.

WHAT STILL DOES NOT = The hero includes real application evidence where the primary concept foreground shows only studio objects. Exact object contours and engraved letterforms differ.

WHY ANY DIFFERENCE IS NECESSARY = The directive requires authentic Cache Vault evidence and selected G. The environment is decorative art, never software or factual evidence. There is no longer an accepted photographic-richness gap.

## Overall desktop density and continuity

REFERENCE DESIGN = A continuous poster-like page: hero → proof → two-row mosaic → three-product strip → ending.

ACTUAL IMPLEMENTATION = The exact sequence is built, with no grid gutters or intervening plain-black sections. The final desktop page is approximately2442px at1440 width, versus2160px for a proportionally scaled reference and6162px for the rejected implementation.

WHAT NOW MATCHES = Page structure, dense pacing, contiguous atmospheric scenes, serif hierarchy, material transitions, distinct product color and visual resolution.

WHAT STILL DOES NOT = The implementation is about13% taller than the proportionally scaled primary design.

WHY ANY DIFFERENCE IS NECESSARY = Real release records, legible application inspection, accessible actions and current provenance require modest additional space. This is visible in the complete equal-width comparison; no vertical rescaling hides it.

## Mobile

REFERENCE DESIGN = The supplied poster does not define a mobile layout, but its design family remains binding.

ACTUAL IMPLEMENTATION = At360/390/430, the same foundry material spans headline, actions and a large real app; maker detail follows. The physical ledger stays readable, the phone dominates a blue scene, Runroom provides controlled horizontal inspection, and secondary strips remain compact.

WHAT NOW MATCHES = The material world, editorial scale, product differentiation, overlapping depth and environmental resolution survive mobile.

WHAT STILL DOES NOT = Four desktop cells become intentional full-width scenes; the ledger expands to expose full data. Runroom cannot show its entire desktop interface at readable scale simultaneously.

WHY ANY DIFFERENCE IS NECESSARY = Readability, complete evidence and touch/keyboard inspection require responsive recomposition. It remains a cinematic sequence, not a plain list of generic cards.

## Motion and catalog boundary

REFERENCE DESIGN = Static authority defines visual states; the directive requires restrained, interruptible motion and a useful separate catalog.

ACTUAL IMPLEMENTATION =300ms opacity/12px reveals enhance already-visible content; reduced motion cancels active reveals. The existing seven-product search/filter/compare catalog is byte-preserved.

WHAT NOW MATCHES = Quiet motion serves the scenes, and homepage storytelling stays separate from catalog utility.

WHAT STILL DOES NOT = No continuous parallax or ongoing effects are used; a still reference cannot establish temporal behavior.

WHY ANY DIFFERENCE IS NECESSARY = Constant animation was explicitly excluded. Actual normal/reduced-motion states are validated in browser evidence, while catalog behavior remains practical and unchanged.
