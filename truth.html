Machine-Readable Records

Public Truth

Every record below is generated at build time from the same canonical site-manifest.json product facts rendered across this site — release versions, artifact checksums, verification receipts, and proof links. Nothing here is hand-maintained.

What this is

One claim, one record

These JSON documents exist so a human, script, or verifier can ask "what does Proof Foundry currently claim publicly about this product?" and receive one deterministic, versioned, sanitized answer — the same answer the HTML pages render.

Per-product records

/truth/schema-v1.json — the versioned contract each record conforms to.

Deterministic

Truth records carry source commit and tree identity, not a build timestamp. The same source produces the same bytes — verifiable by anyone who rebuilds.

Stability

Contract versioning

schemaVersion identifies the contract shape

Every record carries schemaVersion: 1 and conforms to schema-v1.json.

Facts change, the contract stays

Versions, dates, checksums, availability and links update as products release — without changing the contract version.

Breaking changes get a new version

Any change to the contract's shape or field meaning publishes under a new schema version. v1 records keep their meaning forever.
