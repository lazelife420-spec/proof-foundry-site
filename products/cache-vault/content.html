Full Product Workflow

Local clipboard workspace for Windows & mobile.

Capture, organize, retrieve, act, inspect history, and export—all on your own machine.

01

Multi-Format Capture

Keep copied text snippets, code, URLs, and image buffers in a searchable local database rather than overwriting past history.

02

Collections & Cleanup

Organize essential clips into named collections, pin Favorites, and review Vault Cleanup Suggestions for duplicate groups.

03

Quick Paste Retrieval

Access your clip history instantly from any application using global hotkeys without losing focus in your current window.

04

Per-Clip Activity Ledger

Inspect timestamps and recorded actions for every clip: creation, copying, pinning, collection moves, and export package membership.

05

Command Center Actions

Execute Phase 1 Hotkey Actions: open the vault or Quick Paste, pause or resume capture, save the current clipboard to a Safe, run a saved Vault Macro, or lock the vault instantly.

Note: Limited to implemented Phase 1 Hotkey Actions. Text Expansions reflect future phases.

06

Receipt-Backed Exports

Export selected content as a portable folder/ZIP with a readable index (index.html), machine-readable manifest (manifest.json), and stamped receipt (stamped_receipt.txt).

07

Android Companion

Pair with your Android phone over local Wi-Fi via QR code to transfer text clips and URLs directly between devices without cloud servers.

Note: Desktop {{product.versionLabel}} pairs with Android companion v{{product.companionVersion}} public baseline; v{{product.companionCandidateVersion}} (code 8) is qualified on hold.

08

Separate Local Profiles

Keep profile databases isolated from each other. Core desktop features stay local, and the optional companion communicates over your local network.

Install, update, uninstall & leftover data

Install
The public Windows {{product.versionLabel}} release is available from Proof Foundry downloads. The Windows package is unsigned — verify the SHA-256 before running.
First run
Clipboard history is collected locally after launch. No account or cloud setup exists.
Update
No updater is documented. The current {{product.versionLabel}} release would be replaced by a fresh download; verify the SHA-256 of any new package.
Uninstall
Uninstall via Windows Settings → Apps. The Android companion uninstalls via Android Settings → Apps.
Leftover data
Clipboard history, snippets, image buffers, and Quick Paste ledgers persist in a local SQLite database under %APPDATA%\CacheVault\. Uninstalling does not remove that directory; delete it to remove all local data.

Privacy & Data Control

Frequently Asked Questions

What data is captured by Cache Vault?

Text snippets, developer code, URLs, and image buffers copied to your system clipboard while Cache Vault is active.

Is my clipboard data uploaded to the cloud?

No cloud account or cloud storage is required. Core desktop features work locally on your machine. The optional Android companion communicates directly with your desktop over your local network.

Where is clip history stored?

Clips are stored in a profile-isolated local database within your local profile application data directory.

How do portable exports work?

Selected collections are exported to a portable folder/ZIP containing an index.html file for reading, a manifest.json for parsing, and a stamped_receipt.txt recording export details.

01

Stored on your device

System clipboard history, code snippets, image buffers, and Quick Paste ledgers are stored in a profile-isolated SQLite database in %APPDATA%\CacheVault\.

02

Network & LAN companion egress

Desktop clipboard core operates offline with zero cloud account requirements. Optional mobile companion sync transfers clips directly over your local Wi-Fi network via an authenticated TCP socket.

03

Telemetry & retention

Zero background telemetry or cloud analytics. Clips persist locally up to configurable limits. Delete individual entries, clear collections, or export portable ZIP archives at any time.
