Privacy & Data Flow

Local-first clipboard vault. Optional LAN pairing.

Evidence-backed behavior for Cache Vault Windows {{product.versionLabel}} and Android companion v{{product.companionVersion}}.

01

Stored on your device

System clipboard history, code snippets, image buffers, and Quick Paste ledgers are stored in a profile-isolated SQLite database in %APPDATA%\CacheVault\.

02

Network & LAN companion egress

The desktop core needs no cloud account. If you pair the optional Android companion, selected text clips and URLs are sent to the paired phone over your local Wi-Fi network.

03

Telemetry & retention

The release does not send background telemetry or cloud analytics. Clips persist locally up to configurable limits. Delete individual entries, clear collections, or export portable ZIP archives at any time.
