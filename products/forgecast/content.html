Set up and keep it yours

Install, update, uninstall & leftover data

Install
Download the APK on your Android 8+ phone and open it. Android will ask you to allow installation from your browser or file manager (unknown-apps permission).
First run
On first launch ForgeCast asks for the locations you want forecasts for and fetches weather over HTTPS; there is no account, sign-in, or background tracking. Add a location to get Today / Plan guidance.
Update
No automatic background auto-update. From v0.3.4, install the new APK normally — settings and data carry over. From v0.3.3 or earlier, a signing change requires uninstalling the old app first, which removes its local settings and data.
Uninstall
Uninstall from Android Settings → Apps like any app.
Leftover data
App-private storage (/data/data/{{product.packageId}}/) holds saved locations, wear/bring settings, and widget forecast caches. Uninstalling removes this app-local data unless separately preserved.

Privacy & Data Flow

Functional weather queries. Zero analytics tracking.

Evidence-backed behavior for ForgeCast Android {{product.versionLabel}}.

01

Stored on your device

Saved locations, wear/bring guidance settings, and widget forecast caches persist in Android app-private storage (/data/data/{{product.packageId}}/).

02

Network egress

Fetches weather forecasts over HTTPS for user-selected or coarse/fine location targets. Forecast queries send location coordinates to public weather APIs to return live weather data.

03

Telemetry & tracking

Zero background telemetry, analytics SDKs, or ad tracking frameworks. Forecasts cache locally for offline viewing until TTL expiration.
