An archive-first idea

The surviving project records begin under Smart Clean. The June 2026 changelog describes its archive-first direction, followed by the Cleanroom rebrand on 10 June. That documented design principle—not an invented disaster or founder anecdote—is the useful origin story: inspection and a retained copy come before an irreversible cleanup.

12 June 2026 — the changelog records file-type detail in receipts.

A version discrepancy we will not hide

The existing website describes v1.0.7. GitHub separately records a v1.0.10 Windows installer and release notes covering scanner, custody, conservative leftover handling and interface improvements. Those records disagree on what the website should promote. This draft preserves the distinction and does not silently replace the download or call the newer package independently field-tested.

Review, archive, inspect, restore

Scan the selected locations and inspect the candidates. Archive only the files you intend to remove from their original location. Open the receipt to see what changed, and use the retained archive to restore eligible files when needed. Archiving on the same disk is not the same as freeing disk space; space is reclaimed when retained data is actually removed.

“A way back” has a boundary

A retained archive can support restoration. Permanent deletion and pruning an archive remove that route back and must never be covered by an “undo anything” promise. The unsigned v1.0.10 release metadata is available, but adoption of that release on this website remains unresolved.

Install, update, uninstall & leftover data

Install
Run the downloaded {{product.artifacts.0.filename}} installer. The installer is not Authenticode-signed, so Windows SmartScreen may prompt — choose More info → Run anyway after verifying the SHA-256.
First run
First-launch behavior beyond the installer is not described in the public source; the Inspect → Archive → Restore workflow is the main loop. If anything unexpected appears, use the diagnostic template on the support page.
Update
The public source does not describe an updater. {{product.candidateStatus}} Watch the roadmap or release record for a new published installer and verify its SHA-256 before running it.
Uninstall
Uninstall via Windows Settings → Apps (standard for an Inno Setup installer). The public source does not document a separate uninstall step.
Leftover data
Archived files remain on local disk in %APPDATA%\Cleanroom\Archive\ until restored or explicitly purged by you. Uninstalling the app does not restore or delete that archive; restore what you need first, then remove the directory if you want it gone.
