Install, update, uninstall & leftover data

Install
Run the downloaded {{product.artifacts.0.filename}} installer. The installer is not Authenticode-signed, so Windows SmartScreen may prompt — choose More info → Run anyway after verifying the SHA-256.
First run
First-launch behavior beyond the installer is not described in the public source; the Inspect → Archive → Restore workflow is the main loop. If anything unexpected appears, use the diagnostic template on the support page.
Update
The public source does not describe an updater. The next build ({{product.candidateVersionLabel}}) is in progress; watch the roadmap or release record for a new published installer and verify its SHA-256 before running it.
Uninstall
Uninstall via Windows Settings → Apps (standard for an Inno Setup installer). The public source does not document a separate uninstall step.
Leftover data
Archived files remain on local disk in %APPDATA%\Cleanroom\Archive\ until restored or explicitly purged by you. Uninstalling the app does not restore or delete that archive; restore what you need first, then remove the directory if you want it gone.
